# Nicky Olivier Website – Built with React

This is a modern, responsive website built for Nicky Olivier, using React. The site features dynamic content rendering and optimised performance for both SEO and speed.

## Tech Stack

- React
- CSS
- Vercel

## Getting Started

1. Clone the repo:

   ```bash
   git clone https://github.com/deshandeshandeshan/nickyolivier.git
   cd client-website

   ```

2. Install Dependencies:
   npm install

3.  `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\

## Deployment

This site is deployed via [Vercel](https://vercel.com/). Any changes pushed to the `master` branch are automatically deployed.

To trigger a rebuild manually:

- Go to the Vercel dashboard
- Click "Deployments"
- Select "Redeploy"
